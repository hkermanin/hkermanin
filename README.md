I build tools that let people use blockchain applications through Telegram.
One of my projects is a Rust bot that lets a user create a wallet, check its
balance, and send USDC on Arc Testnet without leaving the chat.

| Project | What you can find in the repo |
| --- | --- |
| [ArcCircleBot](https://github.com/hkermanin/arc-bot) | A Telegram wallet built with Rust, PostgreSQL, and Circle Wallets. Users review the recipient and amount before confirming a transfer. |
| [Arc Wallet](https://github.com/hkermanin/arc-wallet) | A small Rust example for developers who want to create their first wallet set and wallet on Arc Testnet using the Circle API. |
| [Technocore Gateway](https://github.com/hkermanin/technocore-telegram-bot) | A Python Telegram client for decentralized identities and messaging, with screenshots and notes on its architecture and security model. |

I also study smart contract security. My [Ethernaut repository](https://github.com/hkermanin/Ethernaut)
contains my Solidity work for levels 22–32.
